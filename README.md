# 📚 РГР по дисциплине «Технологии программирования»  
## 🎯 Тема: «1.3.2. Частотный словарь. АВЛ»

---

## 📌 Общая постановка задачи
**Частотный словарь на основе АВЛ-дерева**  
Разработать алгоритм формирования частотного словаря:
- Определить понятие "слово"
- Обработать текст, сохраняя слова и их частоту встречаемости
- Выявить топ-3 самых частых слов  
**Реализация:** `std::map`  
**Структура узла АВЛ-дерева:**
- Ключ: слово
- Значение: количество повторений

---

## 🔍 Алгоритм решения
**Определения:**  
🔹 *Слово* — последовательность букв английского алфавита между разделителями (пробел, табуляция, EOF).

**Шаги выполнения:**  
1. Создать словарь (`std::map<string, int>`)
2. Открыть файл (имя — аргумент командной строки)
3. Читать слова, приводя к lowercase и игнорируя пунктуацию
4. Заполнять словарь: `map[word]++`
5. По команде выводить топ-3 частых слов

**Поддерживаемые команды:**  
```bash
help                # Справка
create <name>       # Создать словарь
remove <name>       # Удалить словарь
print <name>        # Вывести словарь
sort frequency <name>  # Сортировка по частоте
sort alphabet <name>   # Сортировка по алфавиту
delete <key>        # Удалить слово
find <key>          # Найти частоту слова
top <name>          # Топ-3 слов
open <filename>     # Загрузить текст из файла
write <filename> <name> # Сохранить словарь
stop                # Завершить редактирование
save                # Сохранить изменения
